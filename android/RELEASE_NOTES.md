ScamShield Guardian for Android — hackathon preview, version 1.0.

- Check shared messages and links with ScamShield.
- Optional incoming SMS, message-notification, and call-number alerts.
- Open the dashboard and analysis details in the app.

Requires Android 8.0 or later. Download `ScamShield.apk` and open it on the phone to install.
Enable the protection features you want in the app. Analysis requires the ScamShield backend
to be online; the server address can be changed in the app.

This preview uses the existing ScamShield debug signing certificate. Keep the same signing
identity for updates. `ScamShield.apk.sha256` contains the download checksum.
